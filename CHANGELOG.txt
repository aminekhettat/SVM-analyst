SVM Analyst – Changelog
========================

v1.4.5 – 2026-06-10
--------------------
Feature release – Embedded C Code Generator (Roadmap Feature #11).

New features:
- codegen: new module svm_shaper/codegen.py implementing a MISRA C:2012-compliant
  C code generator for all 11 supported PWM modulation strategies.
  · CodegenOptions dataclass: project_name, author, organization,
    svm_analyst_version, custom_injection_percent.
  · CCodeGenerator.generate(modulation, options) returns a (header, source) tuple.
  · Generated header (.h): include guard, Doxygen \file / \brief / \author /
    \version / \copyright / \license blocks, full copyright + MIT license text,
    disclaimer, explicit MISRA C:2012 compliance section listing satisfied rules
    (1.3, 2.2, 5.x, 8.4, 10.x, 14.4, 15.5, 17.3, 18.1, 20.1, 21.1), PC-lint /
    FlexeLint compliance statement.
  · Generated source (.c): Doxygen block, static helper wrappers for fmaxf/fminf
    with modulation-namespaced identifiers (avoids symbol collisions in TUs),
    main PWM_<MOD>_ComputeDuty() API with full NULL-pointer check, MI range
    validation, MISRA-conformant single return point (status variable pattern,
    Rule 15.5), /* */ comments only (no // C99-only style).
  · Dedicated numeric constants per modulation (#define TWO_PI, TWO_PI_OVER_3,
    SVM_NORM, PREGAIN, INJ_COEFF, PHASE_SHIFT, SQRT3_OVER_2 etc.) with
    high-precision floating-point literals.
  · All 11 modulation algorithms supported: SINUSOIDAL (SPWM), THIPWM 1/6,
    THIPWM 1/4, CUSTOM_THIPWM, SVM, DPWM_120_MAX/MIN, DPWM_60_0/1/2, DPWM_30_3.
  · CUSTOM_THIPWM: generates an extra inj_ratio parameter (float32_t, [0,1])
    with its own range validation guard.
- gui: CCodeDialog – a modal dialog accessible from Tools → Generate C Code…
    • Two-tab QTabWidget: "Header (.h)" and "Source (.c)", each with a
      read-only monospace QPlainTextEdit.
    • Save Header / Save Source buttons (QFileDialog with .h/.c filters).
    • Copy Header / Copy Source buttons for clipboard workflow.
    • All widgets carry accessibleName and accessibleDescription.
    • Pre-filled with current simulator configuration (modulation, MI,
      project name, author).
- tests: 580 new tests in tests/test_feature_codegen.py achieving 100%
  branch coverage of codegen.py, including parametrized checks for all
  11 modulations and Qt smoke tests for CCodeDialog.

v1.4.2 – 2026-06-09
--------------------
Feature release — overmodulation region, MI > 1 (Roadmap Feature #6).

New features:
- modulations: generate_modulated_pwm() accepts a new modulation_index
  parameter (default 1.0). When MI > 1.0, the reference waveforms are scaled
  above the carrier bounds, causing duty-cycle clamping in the affected PWM
  periods (overmodulation). For SINUSOIDAL/THIPWM the linear boundary is
  MI = 1.0; for SVM/DPWM modes the references peak at ~0.866, so
  overmodulation begins near MI ≈ 1.15.
- core: SimulatorConfig gains modulation_index: float = 1.0. SimulationResult
  gains saturation_percent (0–100 %, fraction of PWM periods with D ≤ 0 or
  D ≥ 1 across the worst-case phase) and is_overmodulation (True when
  MI > 1.0 and at least one period is saturated).
- gui: "Mod. Index:" spinbox (0.10 – 1.50, step 0.01) added below the
  Amplitude row.  An inline warning label ("⚠ OM X%") turns red when
  overmodulation is active.  Info-text panel gains a dedicated
  "Modulation Index / Overmodulation" section showing MI, saturation %, and
  a OVERMODULATION ACTIVE flag when applicable.
- tests: 32 new tests in test_feature_overmodulation.py covering F16
  (generate_modulated_pwm MI parameter), F17 (duty-cycle clamping
  monotonicity), F18 (six-step approach), F19 (saturation_percent /
  is_overmodulation fields), F20 (THD increase with MI), F21 (backward
  compatibility with MI = 1.0 default).

v1.4.0 – 2026-06-09
--------------------
Feature release — dq-frame phasor diagram (Roadmap Feature #5).

New features:
- analysis: compute_dq_phasors() — Clarke (αβ) and Park (dq) transforms for
  SVM phase voltages.  Returns the αβ trajectory arrays plus DC-averaged Vd/Vq,
  voltage phasor magnitude and angle, and current phasor coordinates using the
  amplitude-invariant Clarke convention.
- core: SimulationResult extended with 9 new dq fields: dq_valpha, dq_vbeta
  (Clarke trajectory arrays), dq_vd, dq_vq, dq_vs_magnitude, dq_vs_angle_deg,
  dq_id, dq_iq, dq_is_angle_deg.  All fields default to zero / empty arrays for
  backward-compatible manual SimulationResult construction.
- gui: DqPhasorDialog — matplotlib 1×2 dialog (View → dq-frame Phasor Diagram)
  showing the αβ Clarke trajectory with SVM hexagon (left panel) and the
  fundamental voltage phasor Vs and current phasor Is as annotated arrows in the
  dq Park frame (right panel).
- gui: _show_dq_phasor() method on SvmShaperApp; dialog auto-refreshes on
  _on_simulation_finished when already open.
- tests: 29 new tests in test_feature_dq_phasor.py covering compute_dq_phasors
  edge cases, Clarke/Park correctness, phasor magnitudes and angles, and
  SimulationResult population via run_simulation.

v1.3.0 – 2026-04-08
--------------------
Minor release — CMV plot, DC bus current ripple panel, comparison mode.

New features:
- core: SimulationResult extended with CMV array (cmv) and statistics
  (cmv_mean, cmv_rms, cmv_min, cmv_max, cmv_pp).  Formula: CMV = (Va+Vb+Vc)/3;
  mean ≈ Vdc/2 for ideal SVM; deviations reveal zero-sequence voltage.
- core: SimulationResult extended with normalised DC bus current ripple
  (dc_bus_current_norm) and its statistics (min/max/rms/pp).
  Formula: I_dc_norm = Da·sin(ωt+φ) + Db·sin(ωt−2π/3+φ) + Dc·sin(ωt+2π/3+φ).
- gui: PlotCanvas gains a CMV panel (purple, scrollable) with show/hide checkbox
  and update_cmv() method.
- gui: PlotCanvas gains a DC bus current ripple panel (red, scrollable) with
  show/hide checkbox and update_dc_bus_ripple() method.
- gui: Splitter now has 5 panels with stretch factors 3/3/2/2/2.
- gui: Comparison mode — "Save Reference" button stores a SimulationResult
  snapshot; set_reference_static(), update_reference_waveform(), clear_reference()
  draw grey dashed overlays on waveform, FFT, and duty cycle plots.
- gui: "Clear Reference" button removes all overlays; both buttons are accessible
  via keyboard and screen readers.
- gui: Info box shows ΔTHD, ΔCMV peak-to-peak, and ΔDC bus peak-to-peak when
  a reference is active.
- io: PDF report gains a new CMV + DC bus ripple page (page 5); TOC and page
  numbers updated accordingly.
- io: PDF duty cycle page now uses ax.step(where='mid') for correct staircase
  rendering (bug fix).
- analysis: compute_thd() vectorised — replaced O(max_order × bins) per-harmonic
  Python loop with np.rint(orders * f0 / freq_resolution); low-RPM simulations
  improved from ~68 s to ~0.2 s per point.
- tests: 55 new tests across 4 feature test files (test_feature_cmv.py ×15,
  test_feature_dc_bus_ripple.py ×14, test_feature_comparison.py ×21,
  test_feature_duty_staircase_pdf.py ×5).  Total: 321 tests.
- ROADMAP.md created documenting all 10 agreed future features.
