SVM Analyst – Changelog
========================

v1.2.2 – 2026-04-08
--------------------
Patch — duty cycle metrics, FFT, dead-time impact, and PDF report inclusion.

- core: SimulationResult extended with per-leg (A/B/C) min/max/mean/RMS duty
  cycle statistics, phase-to-phase duty cycle arrays (D_AB, D_BC, D_CA) and
  their statistics, dead_time_duty_limit scalar (fraction of PWM period), and
  FFT arrays for the duty cycle signal (Phase A, sampled at pwm_frequency_hz).
- core: run_simulation() now computes all new fields; duty cycle FFT reuses
  the existing compute_fft() with sampling_rate = pwm_frequency_hz.
- gui: PlotCanvas._duty_fft_plot added below the duty cycle envelope —
  toggled via "Show Duty Cycle FFT" checkbox.
- gui: Dead-time limit reference lines (dashed red) drawn on the duty cycle
  envelope plot at D_min = limit% and D_max = (1−limit)%.
- gui: PlotCanvas.update_duty_cycle() gains dead_time_duty_limit parameter.
- gui: PlotCanvas.update_duty_fft() new method.
- gui: Info text box now shows a "Duty Cycle Metrics" section with per-leg
  and phase-to-phase min/max/avg/RMS values and dead-time duty loss.
- io: export_report_pdf() gains a "Duty Cycle Envelope + FFT" page (page 4)
  with matplotlib subplots, dead-time horizontal lines, and TOC updated.
- io: Parameter summary page now includes duty cycle statistics.
- tests: 12 new tests added (test_core.py ×8, test_gui.py ×6); total 265.

v1.2.1 – 2026-04-07
--------------------
Patch — duty cycle plot enhancements.

- gui: duty cycle Y-axis now shows values in % (0–100) with 2 decimal places
  via a custom _DutyPercentAxisItem tick formatter
- gui: per-phase visibility checkboxes (Phase A/B/C) added above duty cycle plot
- gui: new PlotCanvas.set_duty_phase_visible() for programmatic phase toggling
- tests: added full coverage for compute_duty_cycle_envelope, SimulationResult
  duty cycle fields, and all new GUI methods; fixed SimulationResult fixtures in
  test_io.py and test_io_extended.py to include duty cycle fields

v1.2.0 – 2026-04-07
--------------------
Minor release — code signing guidance and distribution hardening.

- docs: documented Windows code-signing options for the distributed EXE;
  recommended SignPath Foundation (free for open-source) as the path to a
  SmartScreen-trusted binary without hardware cost.
- chore: minor version bump; no functional changes to application code.

v1.1.5 – 2026-04-07
--------------------
- feat: auto-update on launch — at startup the application silently queries
  the GitHub Releases API; if a newer version is found the user is prompted
  and, upon confirmation, the update is downloaded in the background with a
  progress dialog, the replacement batch script is written, and the app
  exits so the new EXE is swapped in automatically.
- Added svm_shaper/updater.py (pure-Python, no Qt dependency) with helpers:
  _parse_version, fetch_latest_release, is_update_available, download_update,
  apply_update.
- Added tests/test_updater.py with 29 unit tests covering all updater paths.

v1.1.4 – 2026-04-07
--------------------
- Administrative: version number bumped from 1.1.3 to 1.1.4 to obtain a
  clean GitHub release tag (the v1.1.3 tag was consumed by an immutable
  auto-release stub and could not be reused). No functional changes.

v1.1.3 – 2026-04-07
--------------------
- UI: window now opens maximized on launch for an optimal graph view.
- UI: graph (PlotCanvas) uses Expanding/Expanding size policy so it fills all
  available space when the window is maximized or resized.
- UI: control panel uses QWidget with Maximum vertical policy; groups no
  longer steal vertical space from the graph on wide/tall windows.
- UI: info-box height capped at 180 px; minimum window size raised to 1280×720.
- UI: resizeEvent aspect-ratio guard (4:3 – 8:3) prevents broken portrait or
  extreme ultrawide layouts when the window is manually resized.
- UI: single-instance lock – attempting to open a second instance shows a
  warning dialog and exits immediately (Windows named mutex; POSIX flock).
- Accessibility: explicit Tab-key order set across all 23 interactive widgets;
  initial keyboard focus lands on the Author field when the window opens.
- Tooling: added .github/agents/check-ci.agent.md VS Code agent.
- Tests: 33 GUI tests (up from 24), 48 accessibility tests; full suite 212 tests.

v1.1.2 – 2026-04-07
--------------------
- Fix: scipy was excluded from the PyInstaller bundle, causing the EXE to crash
  on launch with "ModuleNotFoundError: No module named scipy".
- Removed PyQt6 from the project venv; PySide6 is now the sole Qt binding,
  eliminating the PyInstaller Qt-bindings collision that prevented clean builds.
- EXE rebuilt from scratch with the corrected spec (105 MB, scipy included).

v1.0.2 – 2026-04-06

v1.0.1 – 2026-03-09
--------------------
- Initial public release.
- Modulation methods: Sinusoidal PWM, THIPWM 1/6 and 1/4, SVM,
  DPWM 120 max/min, DPWM 60 variants, DPWM 30 (DPWM3).
- Real-time FFT with dual THD computation (line voltage A and phase voltage AB).
- Dead-time model with diode conduction and configurable forward voltage.
- PWM alignment modes: left, right, center (MCU-compatible timer semantics).
- Export: waveform/FFT to CSV, plot to PNG, full report to PDF.
- Save/load simulation configuration (JSON).
- THD parameter sweep by speed (RPM) or PWM frequency.
- SVM hexagon view with active sector highlighting.
